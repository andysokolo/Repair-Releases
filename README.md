# Repair downloads

Android APK releases for **Repair**, with **AIMA**, the Artificially Intelligent Maintenance Assistant.

[Download the latest release](https://github.com/andysokolo/Repair-Releases/releases/latest)

Install `Repair.apk` on Android 8.0 or newer. Each build supports ARM64 phones and x86_64 emulators. Android may ask you to allow installation from your download source.

The updater-enabled app checks for newer releases, asks before downloading, verifies the APK and opens Android’s installation confirmation. Users of earlier versions need to install an updater-enabled build manually once.

This is a development preview. A Repair workspace account is required to access hosted maintenance records and AIMA. Credentials are not distributed here.

This repository contains downloads and release information only. Application source is maintained in a separate private repository. Every release includes a SHA-256 checksum.
